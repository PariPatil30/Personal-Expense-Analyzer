# 💰 Personal Expense Analyzer

> A modern personal finance dashboard that helps users track, analyze, and understand their spending habits.

🔗 **Live Demo:** https://personal-expense-analyzer-and-tracker.streamlit.app/

---

## 📌 About the Project

Personal Expense Analyzer is a smart expense-tracking and analysis application built using Python and Streamlit.

The application allows users to record their daily expenses, manage transactions, analyze spending patterns, and visualize their financial data through an interactive dashboard.

The project uses SQLite for persistent data storage and Pandas for data processing and analysis.

---

## ✨ Features

- ➕ Add new expenses
- 📊 Interactive expense dashboard
- 📅 Filter expenses by time period
- 🔎 View complete expense history
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 💰 Track total spending
- 📈 Analyze spending patterns
- 🚨 Expense anomaly detection
- 🔮 Expense prediction
- 📥 Download filtered expense data
- 🌙 Modern dark-themed interface
- 💾 SQLite database for persistent storage

---

## 🖥️ Dashboard

The dashboard provides an overview of spending activity and helps users understand their financial behaviour through data-driven insights.
