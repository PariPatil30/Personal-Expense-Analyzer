## 🚀 Usage

1. Open the deployed application using the Streamlit link.
2. Go to **Add Expense** to record a new expense.
3. Enter the amount, category, date, and description.
4. View your spending in **Expense History**.
5. Use **Edit Expense** or **Delete Expense** to manage transactions.
6. Set your budget from the **Budget** section.
7. Check the **Dashboard** to view spending trends and analytics.
8. Explore **Advanced Analytics** for additional insights.
